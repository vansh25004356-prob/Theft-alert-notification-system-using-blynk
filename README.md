# Theft Alert Notification System using Blynk IoT

This project is an **IoT-based theft alert notification system** developed using **ESP8266** and an **IR sensor**.  
The system detects motion and sends **real-time alerts to the Blynk IoT mobile app and email (Gmail)**.

---

## 🔍 Project Overview

The objective of this project is to build a simple and effective theft detection system using IoT technologies.  
When motion is detected by the IR sensor, the ESP8266 processes the signal and sends instant notifications to the user.

## 🔄 Working Principle
1. The IR sensor continuously monitors for motion.
2. When motion is detected, the sensor sends a signal to the ESP8266.
3. ESP8266 connects to WiFi and communicates with the Blynk IoT cloud.
4. A **notification is sent to the Blynk mobile app**.
5. A **simultaneous alert email is sent to the registered Gmail account**.
6. Alerts stop when motion is no longer detected.
